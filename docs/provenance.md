# Provenance and scope of copying

**Source:** private `mark-alfred-griffiths/ubel-jpc`, reviewed main revision `7626b1397c802ee97d3ded30ec83e29e594e55b3` (20 November 2026). The uploaded `ubel-jpc-main.zip` supplied the copied main-branch source bytes. GitHub access confirmed the repository is private and the reviewed revision is among its latest main commits; the working materials are *not* a clone of its original `.git` history.

**Feature-branch historical evidence:** `feature/path-integral-forecast`, report `docs/multimodal_forecast_final_report_20261120.md`, original referenced revision `713a8773973b4d25883fa64fd0ed01efea9553c6`. The fetched report and forecasting module matched that reference commit's Git blob content; no forecasting implementation was copied here. The branch ref itself should be rechecked before any later historical comparison.

**Earlier separate project:** `mark-alfred-griffiths/decoupled-predictive-coding-benchmarks`; mathematical influence and guidance from Professors Christopher Buckley and Karl Friston should be acknowledged, without implying third-party copyright assignment or co-authorship of this curated code.

Source modules and source tests are copied **byte-for-byte**. They keep their historical `ubel_jpc` Python namespace, original docstrings, and references to optional JPC. The new packaging, two examples, source mapping, local scripts and documents are curated additions. Source SHA256 hashes appear in `source_hashes.json` and can be checked against the original matching source archive with `scripts/check_source_hashes.py` (or independently with `sha256sum`).

No native JPC code or forecasting benchmark is vendored. No original `.git` metadata, historical run directories, participant data, unreleased proposal documents, collaborator communications, or GPU CSV archives are copied. The historical source's exact model-recovery and forecasting results remain **reported historical evidence**, not validated claims on the fresh curated tests.

**Original main and feature branch remain unchanged.** This is a separate curated Git history that began with a new initial commit and was pushed to its own GitHub repository, initially private and now public. It is deliberately not a fork/mirror of the original private Git history. The original `ubel-jpc` remains private.
